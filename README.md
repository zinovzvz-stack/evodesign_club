# 🌌 EVODESIGN | THE GALAXY OF ZINO
موقع متكامل يجمع بين الأكاديمية البرمجية، معرض التصاميم، ومتجر الملحقات.

## 🛠 التقنيات المستخدمة:
- **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6)
- **Backend:** Firebase (Firestore, Auth, Hosting)
- **UI Style:** Cyber-Neon (Blue, Purple, Orange)

## 📱 المميزات:
- متجاوب بالكامل مع الهواتف والحواسب.
- لوحة تحكم سرية للمطور ZINO.
- نظام تتبع عدد الزوار.
